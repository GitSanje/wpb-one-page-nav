# WPB One Page Nav

WPB One Page Nav is a lightweight WordPress plugin for WPBakery Page Builder that adds a floating page navigation panel for your one-page layout.

## Features
- Floating, draggable navigation panel
- One-click collapse and expand for the full navbar
- Navigation items built from WPBakery rows
- Custom labels and anchor IDs for each row
- Simple row-level controls for showing or hiding items in the nav

## How it works
1. Edit a page with WPBakery Page Builder.
2. Open the row settings for the sections you want to appear in the navigation.
3. Set a navigation label and optional anchor ID.
4. Enable "Show in Navigation" for rows you want included.
5. Save the page and open it in the editor view to see the floating navbar.

## Usage
- Drag the navbar by using the handle on the left side.
- Use the collapse button to minimize the panel.
- Use the row collapse button to collapse the related WPBakery rows from the editor view.

## Requirements
- WordPress
- WPBakery Page Builder (Visual Composer)

## Notes
This plugin is intended for editor-side navigation assistance and is best used while building or reviewing one-page layouts.
